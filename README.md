# hxyfront-62001 船舶轮机值班记录

源提示词编号：1

面向船舶轮机值班的前端记录系统，轮机员可按固定巡检路线签点、登记并复核漏检、完成交接班闭环。支持值班班次切换、机舱参数看板、异常记录时间线、交接班摘要和按设备筛选的历史记录。数据保存在浏览器本地（localStorage），刷新后保留，后续可扩展成船队统一管理。

## 巡检签点闭环

- **固定路线**：每班按 主机 → 发电机#2 → 泵组#1 → 舱底水 生成固定巡检序列，仅当前待签设备可操作，未到顺序的设备锁定，不能提前签点。
- **每台每班一次**：设备签点成功后即锁定；主机签点读数更新看板（转速、滑油压力、冷却水温、燃油消耗）。
- **整次拒绝**：读数缺失、非数字、超出允许区间，或需运行确认的设备未勾选“已启动”时，本次签点整次拒绝——不产生签点、不推进路线、看板不变，拒绝原因写入异常时间线。
- **漏检复核**：无法签点时可登记漏检，但必须写明原因；漏检进入“待交班复核”，复核人可通过或驳回，驳回后需补充原因重新提交。
- **交接门禁**：路线未走完或存在待复核/驳回漏检时，交接按钮禁用并列出阻断原因；交接完成后本班路线与看板锁定。
- **摘要导出**：按班生成签点进度、漏检状态、异常时间线与交接备注的纯文本摘要（Blob 下载，无外部依赖）。
- **设备筛选**：全部 / 主机 / 发电机 / 泵组 / 舱底水 筛选同时作用于异常时间线和签点历史。
- **本地同步**：全部数据存 localStorage，刷新或关闭页面后保留；支持清空本机数据。
